## 📦 Scripts

| Команда           | Описание                                     |
| ----------------- | -------------------------------------------- |
| `npm run dev`     | Запуск проекта в режиме разработки           |
| `npm run start`   | Запуск полного цикла: сборка + предпросмотр. |
| `npm run build`   | Сборка проекта                               |
| `npm run preview` | Просмотр production-сборки                   |
